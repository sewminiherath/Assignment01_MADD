# Smart Travel - App Assets Checklist

## Required Graphics for Play Store

### 1. App Icon (512x512 PNG)
- **Current:** Using default Android icon
- **Action:** Create custom icon with travel theme
- **Design:** Sri Lanka map or travel compass
- **Colors:** Blue and orange theme

### 2. Feature Graphic (1024x500 PNG)
- **Purpose:** Main banner on Play Store
- **Content:** "Smart Travel - Discover Sri Lanka"
- **Design:** Beautiful Sri Lankan landscape
- **Text:** App name and tagline

### 3. Screenshots (1080x1920 or 1920x1080)
- **Phone screenshots:** 2-8 screenshots
- **Tablet screenshots:** 2-8 screenshots (optional)
- **Content:** Show key app features

### 4. App Description Graphics
- **Short description:** 80 characters max
- **Full description:** Detailed app features
- **Keywords:** Travel, Sri Lanka, tourism, cultural heritage
